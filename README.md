# Corde Bohème

**Tagline**
> Handcrafted macramé, woven with soul.

## Project Goal

Build a production-ready e-commerce backend using Java 21, Spring Boot, Spring Cloud, Microservices, Kafka, Redis, PostgreSQL, Docker, CI/CD, Observability, and System Design best practices.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Cloud
- PostgreSQL
- Docker
- Kafka
- Redis
- GitHub Actions
- SonarQube
- Prometheus
- Grafana
- ELK Stack
- OpenTelemetry
- Testcontainers
